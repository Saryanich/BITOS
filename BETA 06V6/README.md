# BITOS

**BITOS** — проект настольной операционной среды на Python. Репозиторий содержит исходный код интерфейса и системных компонентов, включая рабочий стол, окна и встроенные инструменты, механизм установки BIP-приложений и системные службы.

> **Статус проекта:** активная разработка / экспериментальная версия. Возможны ошибки, неполная функциональность и изменения архитектуры. Не рекомендуется использовать как единственную рабочую ОС или хранить в ней единственную копию важных данных.

## Возможности

В текущем исходном коде представлены следующие компоненты:

- графическая среда с рабочим столом и окнами;
- системные настройки и встроенные инструменты;
- файловая навигация и работа с файлами;
- установка и запуск BIP-приложений;
- системные модули для мониторинга, безопасности, обновлений и обработки ошибок.

Фактический набор функций и их готовность могут отличаться между версиями. Проект развивается, поэтому не все элементы следует считать стабильными.

## Технологии

- Python
- Tkinter / Tcl-Tk для графического интерфейса
- стандартные библиотеки Python и дополнительные модули, используемые отдельными компонентами

## Запуск

### Требования

- Python версии, совместимой с используемым кодом проекта;
- установленный Tcl/Tk (обычно входит в дистрибутив Python для Windows);
- операционная система и окружение, поддерживающие используемые системные вызовы.

### Получение исходников

Склонируйте репозиторий:

```bash
git clone <URL-репозитория>
cd <папка-репозитория>
```

### Запуск

Из каталога проекта запустите основной файл:

```bash
pythonw BITOS/bitos/main.pyw
```

Если `pythonw` недоступен, можно запустить через `python`:

```bash
python BITOS/bitos/main.pyw
```

Путь к главному файлу может отличаться, если вы клонировали репозиторий с иной структурой или запускаете приложение из каталога `BITOS`.

> Запуск и совместимость на конкретной системе могут потребовать дополнительных зависимостей или настроек. Если приложение не запускается, сначала проверьте версию Python, наличие Tcl/Tk и сообщения об ошибках.

## BIP-приложения

BITOS предусматривает формат приложений **BIP** — отдельные приложения, которые устанавливаются и запускаются системным механизмом.

В общих чертах:

1. BIP-пакет содержит приложение и его метаданные.
2. Системный установщик обрабатывает пакет и размещает приложение в системном каталоге приложений.
3. BITOS регистрирует установленное приложение и предоставляет механизм запуска.
4. Для интеграции с файловыми типами приложение может объявлять обработчики расширений и команды, если эта возможность поддерживается используемой версией BITOS.

Перед созданием или модификацией BIP-пакета изучите API-документацию проекта и текущую реализацию установщика. Не полагайтесь на примеры, не проверив их на целевой версии.

## Разработка

Рекомендуемый рабочий процесс:

1. Создайте отдельную ветку для изменения.
2. Изучите соответствующий модуль и его точки интеграции.
3. Сохраняйте обратную совместимость, если это возможно.
4. Проверяйте изменения в изолированном окружении и на тестовых данных.
5. Не включайте в коммиты пользовательские данные, секреты, локальные конфигурации или временные файлы.
6. В описании Pull Request укажите, что изменено, как это проверено и какие ограничения остались.

Для изменений системных функций проверяйте не только синтаксис, но и сценарии запуска, установки, открытия файлов, восстановления после ошибок и удаления приложения — в зависимости от затронутого компонента.

## Безопасность и ограничения

- BITOS находится в разработке; не используйте его для критически важных задач без самостоятельной оценки рисков.
- Перед запуском приложений и BIP-пакетов из непроверенных источников изучайте их содержимое.
- Делайте резервные копии важных данных.
- Не публикуйте токены, пароли, ключи, приватные конфигурации или пользовательские файлы.
- Не заявляйте о совместимости с конкретными версиями Windows, Python или сторонних приложений без проверки на этих конфигурациях.
